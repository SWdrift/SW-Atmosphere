# 大气边缘

针对“大气路径长度最大”的观察几何。它同时包含低层、中层、高层大气，只是不同高度的贡献不同。大气边缘**可以反映整个大气柱**，是进行验证的绝佳视角。

| 中文名称/术语                                  | 几何关系             | 典型画面          | 主要物理效果            |
| ---------------------------------------- | ---------------- | ------------- | ----------------- |
| 大气边缘/地平弧视角（Atmospheric Limb / Limb View） | 视线近似切过行星表面（切线方向） | ISS看到的地球薄蓝色光带 | 最大光程、强散射、边缘辉光     |
| 行星弧/大气弧（Planetary Arc）                   | 远距离看到行星曲率        | 太空中蓝色地球弧线     | 行星曲率 + 大气散射       |
| 大气辉光/边缘辉光（Atmospheric Glow / Limb Glow）  | 大气边缘被太阳照亮        | 黑色背景中的蓝橙色光环   | Rayleigh/Mie 散射   |
| 晨昏线视角（Terminator View）                   | 太阳照射与背光区域交界      | 一半白昼、一半黑暗     | 复杂低太阳角散射          |
| 黄昏视角/暮光带（Twilight View / Twilight Zone）  | 太阳刚低于/高于地平线      | 橙红、紫蓝渐变天空     | 长距离穿透大气           |
| 夜侧大气边缘（Night-side Limb）                  | 夜侧切线观察           | 黑色地球边缘+绿色光带   | 气辉（Airglow）、弱散射   |
| 气辉视角（Airglow View）                       | 观察高层大气自发发光       | 绿色/红色薄层       | O₂、OH、Na 等发光      |
| 背光大气/逆光大气（Backlit Atmosphere）            | 太阳在行星后方          | 类似“宇宙中的蓝色光圈”  | Mie/Rayleigh 前向散射 |
| 反太阳方向视角（Anti-solar View）                 | 观察方向与太阳相反        | 暗面地球+光环       | 后向散射              |
| 向阳侧视角（Sun-facing View）                   | 摄像机朝太阳照射侧        | 白天蓝色地球        | 直接照明、云层明显         |
| 天底视角/正下视角（Nadir View）                    | 摄像机垂直向地面         | 卫星地图视角        | 地表、云、遥感效果         |
| 斜视角（Oblique View）                        | 倾斜观察地球           | 游戏/卫星常见镜头     | 地表+大气混合           |
| 高空视角（High-altitude View）                 | 近地轨道以下           | 飞机/平流层看到地球    | 天空曲率、大气厚度         |
| 近地轨道视角（LEO View）                         | 约160–2000 km     | ISS类似视角       | 大尺度云、大气弧          |
| 地球同步轨道视角（GEO View）                       | 约35786 km        | 气象卫星视角        | 整球云系              |
| 再入视角（Atmospheric Entry View）             | 高速穿过大气           | 航天器进入大气       | 等离子体、热辐射          |
| 大气透射视角（Transmission View）                | 光穿过大气到观测者        | 系外行星观测        | 吸收谱、臭氧特征          |
