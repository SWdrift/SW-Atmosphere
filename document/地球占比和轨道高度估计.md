# 地球占比和轨道高度估计

以最常见的 **相机视场角（水平FOV）= 60°** 为例（假设地球居画面正中）：

| 地球占画面水平宽度比例 | 对应地球视角 (θ) | **轨道高度 (h)** | **轨道分类** | 典型代表/轨道周期 |
| :-- | :-- | :-- | :-- | :-- |
| **100%** (刚好切边) | ≈ 60° | **~420 km** | **LEO** (近地轨道) | 国际空间站（ISS），周期约 92 分钟 |
| **70%** | ≈ 42° | **~1,500 km** | **LEO** (近地轨道高层) | 铱星、部分科学卫星，周期约 115 分钟 |
| **50%** | ≈ 30° | **~3,600 km** | **MEO** (中地球轨道) | 导航卫星的“下边界”，周期约 3 小时 |
| **30%** | ≈ 18° | **~8,500 km** | **MEO** (中地球轨道) | 部分GPS卫星，周期约 6 小时 |
| **17%** | ≈ 10° | **~18,000 km** | **MEO** (中地球轨道高层) | 格洛纳斯（GLONASS），周期约 11 小时 |
| **10%** | ≈ 6° | **~35,800 km** | **GEO** (地球静止轨道) | 通信/气象卫星（静止不动），周期 **24 小时** |
| **6.5%** | ≈ 4° | **~58,000 km** | **HEO / 大椭圆** (高地球轨道) | 部分地磁探测卫星，周期约 26 小时 |
| **4.5%** | ≈ 2.7° | **~100,000 km** | **深空 / 地月空间** | 接近月球轨道高度（38万km），周期约 28 天 |

- **地球边缘几乎贴着画面边框** → 肯定不到 500km，**LEO**。
- **地球像一个篮球，周围有半圈黑色空间** → 几千到一万公里，**MEO**。
- **地球像一个乒乓球，周围全是黑布** → 3.6万公里附近，**GEO**。
- **地球像一颗绿豆，几乎看不见弧度** → 已经飞过月球了，**深空**。

如果 FOV 缩小一半（如 60°→30°），同样高度下地球占比会增大将近一倍（相当于拉近镜头）。
