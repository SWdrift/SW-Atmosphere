# 地球占比和轨道高度估计

以下估计采用半径 `R = 6360 km` 的球形地球、透视相机、水平 FOV `F = 60°`，并假设相机指向地心、地球位于画面中央。

若地球投影直径占画面宽度的比例为 `p`，则：

```text
地球视角 θ = 2 atan(p tan(F / 2))
相机高度 h = R / sin(θ / 2) - R
```

| 画面宽度占比 `p` | 地球视角 `θ` | 相机高度 `h` |
| ---: | ---: | ---: |
| 100% | 60.000° | 6,360 km |
| 70% | 44.012° | 10,614 km |
| 50% | 32.204° | 16,571 km |
| 30% | 19.653° | 30,906 km |
| 17% | 11.211° | 58,750 km |
| 10% | 6.609° | 103,982 km |
| 6.5% | 4.298° | 163,234 km |
| 4.5% | 2.977° | 238,519 km |

这里的高度是距地表高度，不是距地心距离。改变地球半径、镜头投影、FOV、相机指向或裁切方式后必须重新计算，不能把表中数值当作通用轨道分类。

## 轨道和任务参照

下表只用于建立尺度直觉。“画面占比”仍按本文统一模型计算；真实任务的轨道会随时间变化，椭圆轨道的占比也会在近地点和远地点之间变化。

| 位置或轨道 | 著名对象 | 典型高度或距离 | 60° FOV 下的地球宽度占比 |
| :-- | :-- | --: | --: |
| 近地轨道（LEO） | [国际空间站（ISS）](https://www.nasa.gov/reference/international-space-station/) | 距地表 370–460 km | 无法完整入镜 |
| 近地轨道（LEO） | [哈勃空间望远镜](https://science.nasa.gov/mission/hubble/multimedia/online-activities/interactive-orbiting-hubble/) | 距地表约 525 km | 无法完整入镜 |
| 近地轨道（LEO） | [Landsat 8](https://svs.gsfc.nasa.gov/30798) | 距地表约 705 km | 无法完整入镜 |
| 中地球轨道（MEO） | [GPS 卫星星座](https://archive.gps.gov/systems/gps/space/) | 距地表约 20,200 km | 约 42.7% |
| 中地球轨道（MEO） | [Galileo 卫星星座](https://www.esa.int/Applications/Satellite_navigation/Galileo/Galileo_satellites) | 距地表 23,222 km | 约 38.1% |
| 地球静止轨道（GEO） | [GOES 气象卫星等](https://science.nasa.gov/3d-resources/geostationary-operational-environmental-satellites/) | 距地表约 35,786 km | 约 26.4% |
| 高椭圆地球轨道（HEO） | [TESS 系外行星巡天卫星](https://heasarc.gsfc.nasa.gov/docs/tess/what-is-tess.html) | 距地心约 17–59 个地球半径 | 约 10.2%–3.0% |
| 地月尺度 | [月球](https://science.nasa.gov/moon/facts/) | 平均距地心 384,400 km，即距地表约 378,040 km | 约 2.9% |
| 绕月远距逆行轨道任务 | [Artemis I 的猎户座飞船](https://science.nasa.gov/earth/earth-observatory/orion-views-earth-from-afar-150699/) | 最远距地球约 432,210 km | 约 2.6% |
| 日地 L1 | [DSCOVR 深空气候观测站](https://science.nasa.gov/mission/dscovr/) | 距地球约 150 万 km | 约 0.7% |
| 日地 L2 | [詹姆斯·韦布空间望远镜](https://science.nasa.gov/asset/webb/webbs-orbit-at-sun-earth-lagrange-point-2-l2/) | 距地球约 150 万 km | 约 0.7% |

日地 L1/L2 对象不是绕地球运行的普通圆轨道：DSCOVR 在 L1 附近运行，韦布则绕太阳运行并在 L2 附近作晕轨道运动。它们列在这里是为了补充更远的画面尺度，而不是扩展“地球轨道”的分类。

作为交叉检查，距地表 `35,800 km` 时，地球视角约为 `17.353°`，在 60° 透视画面中约占宽度 `26.4%`。距地表 `420 km` 时，地球视角约为 `139.454°`，无法完整放入 60° 视场。
